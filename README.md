# 💻 Fundamentos de Programação com C#

## Módulo 4 — Primeira Atividade

Este repositório contém a resolução da primeira atividade do **Módulo 4 — Fundamentos de Programação com C#**, realizada durante a **Turma 1 — Desenvolvimento Back-End .NET da WoMakersCode**.

A atividade tem como objetivo praticar os principais fundamentos da programação utilizando **C# e .NET**, por meio de exercícios desenvolvidos em aplicações de console.

## 📚 Conteúdos praticados

Durante a atividade, foram trabalhados conceitos como:

* Entrada e saída de dados
* Variáveis e tipos de dados
* Operadores aritméticos
* Estruturas condicionais (`if` / `else`)
* Estruturas de repetição (`for` / `while`)
* Vetores (arrays)
* Manipulação de strings
* Contadores e acumuladores
* Números aleatórios
* Métodos e organização do código

## 📝 Sobre a atividade

A lista é composta por **19 exercícios**, começando por operações e cálculos simples e avançando gradualmente para problemas que envolvem estruturas de repetição, vetores, validações e lógica de programação.

Entre as atividades desenvolvidas estão:

* Operações matemáticas e cálculos
* Conversão de moedas
* Calculadora
* Tabuada e contagens
* Validação de senha e login
* Manipulação de vetores
* Cálculo de médias
* Jogo de adivinhação
* Simulação de um caixa eletrônico

## 🛠️ Tecnologias

* **C#**
* **.NET**
* **Console Application**

## ▶️ Como executar

Com o .NET instalado, clone o repositório e execute:

```bash
git clone <[URL_DO_REPOSITORIO](https://github.com/mariananlemos/lista1_wmc)>
cd <lista1_wmc>
dotnet run
```

## 🎯 Objetivo

Mais do que resolver os exercícios, a proposta desta atividade foi desenvolver a **lógica de programação** e ganhar familiaridade com a sintaxe e os recursos básicos do C#.
